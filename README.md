# FaviconGen

⚡ **Free online favicon generator and converter**

Create professional favicons from images and text instantly. Fast, secure, and easy to use.

## 🚀 Features

- **Image to Favicon**: Convert any image (PNG, JPG, JPEG, WEBP) to favicons
- **Text to Favicon**: Generate favicons from text with customizable fonts and colors
- **Multiple Sizes**: Generate all standard sizes (16x16, 32x32, 48x48, 64x64, 96x96, 180x180, 192x192, 512x512)
- **PWA Ready**: Includes manifest.json and apple-touch-icon
- **Secure**: Client-side processing with comprehensive security measures
- **Fast**: Optimized for speed and performance
- **Multilingual**: Supports Ukrainian, English, and Russian

## 🛠️ Tech Stack

- **Framework**: Nuxt 3
- **Language**: TypeScript
- **Styling**: SCSS with modern mixins
- **UI**: Nuxt UI + Lucide Icons
- **Security**: Custom security utilities and validation
- **Deployment**: Vercel-ready

## 🌐 Live Demo

Visit [favicon-gen.com](https://favicon-gen.com) to try it out!

## 📦 Installation

```bash
# Clone the repository
git clone https://github.com/favicon-gen/favicon-generator.git
cd favicon-generator

# Install dependencies
npm install

# Start development server
npm run dev
```

## 🔒 Security Features

- File type validation with magic number verification
- Input sanitization and XSS prevention
- Rate limiting and memory protection
- Secure headers and CSP policies
- Client-side processing (no data leaves your browser)
